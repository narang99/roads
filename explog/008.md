# Small unet segs

100x100 tile size is working well. I changed the resizing algorithm:
- use `cv2.INTER_AREA`, it makes the mask imperfect but we fine with it
- Instead of finding a crop of some fixed size, and then resizing to desired size (I would take a random sized crop around the object of interest, then resize)
  - We now take the bounding box of the object, and resize that to a desired size
  - For a desired size of the bounding box, we find the padding we need to add on all sides (top bottom left right)
  - We have total padding in each direction, we randomly split that every time (so that object can be placed in corners too, its working quite well)
  - Have a LONG list of different bounding box levels
