## Cones and rods

Eye has approx a 6-7 million cones, located mainly in a single portion of the retina (around the center). The place is called fovea. Cones are highly sensitive to color.  
Each cone is connected to a single nerve ending, helping us resolve fine details.  
Vision generated by cones is called **photopic vision** (or bright light vision)

There are some 75-150 million rods, substantially larger number than cones (100x). They are distributed all over the retina.  
Several rods are connected to a single nerve ending. We don't get a signal from each rod, it is "averaged" out (don't know what the averaging function is). So rods vision is slightly less "fine/detailed" maybe, but it captures a lot more light. They are therefore useful in night. A colorful/bright object can look colorless in night cuz rods don't react to color, and the cones can't capture enough light. The vision generated by rods is **scotopic vision** (dim light vision).

So that is our mapping function. We create a histogram of the cumulative distribution function (CDF, the sum of the number of pixels of all intensities less than current intensity). This gives a new histogram, with a number o

## Fourier series and transform

Fourier series is a series of sines and cosines which can model an arbitrary periodic function. They are a discrete summation series, with a formula to find the coefficients of each sine/cosine inside the series.  

Fourier transformation is the function describing the coefficients of such series when the period limits to infinite (it then becomes an arbitrary function). You can use the coefficients to form a series from it (but the frequency jumps are not infinite) to model the original function.  
This function, describing the coefficients of individual terms says "how much of a single frequency are we adding".  
It describes the power of each frequency. THAT is the frequency domain. That's it.  

Finding properties of the domain is done by translating to-and-fro to the original function (which can be a composition of functions).

## Fundamental convolution <-> fourier theorem

## Band limited functions

A function whose fourier transform is 0 outside `[-mu_max, mu_max]` is called a band limited function.  
The fourier transform of this function would be infinite copies of the fourier transform of the actual function, each copy in a space of size `T` (the sampling period).  
We want to isolate a single copy, run the inverse fourier. This helps us get the original signal.  
If `T < 2*mu_max` (the size of the band limited function), then the fourier of the continuous functions in the fourier of the sampling function would start merging. This merging would make it impossible to isolate a single full fourier transform of the continous function, making it impossible for us to derive the actual function from the samples.  

This is the Nyquist theorem.  


### Isolating the individual FT

We want to isolate the individual fourier transform (`F(mu)`) from the FT of the sampling function (`S(mu)`).  
We can multiply the function `S(mu)` with a function as follows:
```py
H(mu) = T if -mu_max < mu < mu_max else 0
```
So `F(mu) = H(mu) * S(mu)`. We can then run inverse fourier to get the original function back.  
We use `T` instead of `1` because the transform of the sampling function has `1/T` multiplied to it.  

This function is called a low pass filter. It isolates the lower frequencies.  

NOTE: Band limited functions extend from -infinite to infinite (the fourier transform has a specific place where it has non zero values, that makes the function infinitely periodic I think).  This is not true in practice. Imagine signals, they won't exist between infinities. The author is saying they will figure this out later.
